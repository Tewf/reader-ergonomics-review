# Record: what a review lets a reader redo

A reader or a program can redo a review's search, its scores and its figures from what the review records.

| Principle | Claim |
|---|---|
| [Count every search](count-every-search.md) | the protocol records every search string with its count, and says what was not searched |
| [Score grey sources in eight subtotals](score-grey-in-eight-subtotals.md) | a grey source carries Garousi's eight subtotals and a total that adds up, and below the threshold it is an example only |
| [Trace every figure](trace-every-figure.md) | a figure in the review names its source and where it was read, or says it is secondary |
| [Log concepts per result](log-concepts-per-result.md) | the protocol records, per result screened, whether it added a concept, so that a stopping estimator can judge the search |
| [Report the second rater](report-the-second-rater.md) | when two raters score or screen, the review reports how far they agree |
