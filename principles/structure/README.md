# Structure: what a review keeps

A review is kept as nine files, each with one role, written in the order of the five steps. The shapes are in [shapes](../../shapes/README.md).

| Principle | Claim |
|---|---|
| [The nine files](the-nine-files.md) | a review keeps frame, protocol, sources, review, against, state of the art, position, baseline and references, one role each |
| [Five steps, in order](five-steps-in-order.md) | a review runs frame, review, state of the art, position and baseline in that order, and is finished when it names its baseline |
